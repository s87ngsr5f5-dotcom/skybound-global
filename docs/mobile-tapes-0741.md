# 0.74.1 手機刻度帶與載入修補

- 手機空速、高度改回透明刻度帶；IAS 使用 km/h、ALT 使用 m。保留原航向讀值，沒有中央姿態面板或大面積背景。
- 任務、地圖、按鈕、操控、飛行設定及存檔不變。
- 正式部署時每個本地 JS/CSS 加入同一提交的 build 識別，避免沿用上一批快取檔案。外部網址不變。
- latest.html 是固定的最新版入口，轉入同一網站並附新的頁面請求參數。重新載入按鈕也改為新請求；不清除 localStorage 或玩家紀錄。
- 啟動錯誤顯示實際版本與錯誤內容，不再誤寫 0.72。

驗證：53 項既有檢查通過。Edge 與 WebKit 的 iPhone 入口能啟動並進入飛行；852×393 / 393×852 旋轉及畫布中央透明檢查通過。部署識別的重複執行、更新與外部網址保留檢查通過。

限制：使用者手機的初始化中斷未能在測試環境重現，也未取得其檔名／行號。這次改善載入版本一致性和錯誤資訊，不能宣稱已確定修復該實體手機問題。WebKit 測試使用 Windows 自動化瀏覽器，並非實體 iPhone。
