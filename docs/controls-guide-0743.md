# 0.74.3 預設俯仰與主頁操作說明

- 預設俯仰反向：手機左側搖桿向下拉抬頭、向上推低頭。左右滾轉與方向舵不反向。
- 俯仰設定也適用鍵盤／手把／滑鼠飛行輸入；預設鍵盤 ↓ 抬頭、↑ 低頭。環視直接使用拖曳位移，不讀取俯仰反向。
- 舊版操控設定升級為版本 4，一次套用新俯仰預設，保留靈敏度、死區、按鍵等其他資料。之後使用者可自行取消反向，重新開啟仍保留。
- 首頁與左側主選單新增「操控說明」。可切換手機／電腦說明，不會切換實際操作裝置。內容包含姿態、油門、方向舵、環視、雙點回正、地圖、煞車與起飛程序。俯仰方向依當前設定更新。
- 起飛提示同步顯示實際抬頭方向，任務不再固定提示按 ↑。

驗證：54 項檢查。Edge 與 WebKit 測試舊設定遷移、說明入口／裝置切頁、橫直排版、下拉時實際飛行輸入 pitch 為正、右推 roll 為正、環視不反向、取消反向後重載保留。測試為桌面自動化與模擬觸控，非實體手機。
