# 0.77 — 真實地圖航線示意與手機封面更新

## 航線預覽
- 取消純格線示意，使用 OpenStreetMap 標準底圖，將機場及任務三航點從遊戲公尺座標反算 WGS84，再投影至同一套 Web Mercator 畫布。
- 顯示起終點、1–3 航點、方向箭頭、北向與比例尺。相同機場只顯示一個起終點標籤，避免原先重疊。
- 台灣、海外任務均依同樣座標投影，不改任務航點或飛行物理。
- 手機橫向舊樣式原本會隱藏預覽畫布，本版改為固定顯示 220px 高底圖。
- 圖磚僅按玩家當前選定預覽視窗載入，沿用瀏覽器 HTTP 快取，不預抓其他關卡、不打包 OSM 圖磚。記憶體快取上限 64 項。
- 地圖內有可點擊的 OpenStreetMap 署名。參考官方規則：https://operations.osmfoundation.org/policies/tiles/ ；資料授權：https://www.openstreetmap.org/copyright 。可透過 skyboundMapProvider 配置替換圖磚服務。
- 連線失敗時保留航線；台灣顯示既有本地高程示意，其他缺少本地底圖的區域明示只保留航線。無法保證外部圖磚服務永遠可用，亦不把離線替代圖宣稱為完整街道地圖。

## 封面與快取
- 飛機圖像加入方向主光、冷色補光、輪廓高光及 2048px 自投影陰影貼圖，以現有遊戲模型重新渲染。
- 首頁實際背景也改成 hero-v077.jpg，並非只替換 favicon；無重複標題的原圖可供正常選單覆蓋。
- Safari／瀏覽器圖示、Apple Touch Icon、manifest 和分享圖改用新的 v077 檔名，同時保留更新舊資源供舊書籤讀取。
- iPhone 主畫面已安裝捷徑的 OS 圖示快取無法由網站強制清除。本版沒有清除 localStorage、飛行紀錄、金幣或任何存檔。
- 任務側欄數字改為實際總數 35，避免仍顯示舊 19 關。

## 驗證
- 57 項 Node 自動回歸通過；新增 Web Mercator 來回投影、方向與不同尺寸航線入框測試。
- Edge 844×390 一次實際松山預覽載入 OpenStreetMap 底圖，中心為 25.081891,121.585185，5 個路線點（起終點與三航點）座標一致。
- WebKit 中模擬圖磚無法連線，確認台灣本地地形替代、航線保留、手機直橫向畫布可見，且沒有頁面 JS 錯誤。
- 兩種瀏覽器都確認首頁指向新 hero-v077.jpg、Apple Touch Icon 指向新檔名。未取得實體 iPhone，故不宣稱 OS 主畫面快取已在實機更新。
