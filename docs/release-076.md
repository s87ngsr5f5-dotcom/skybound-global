# 0.76 — 飛行駕照與資格任務

## 內容
- 原有 19 個章節保持可直接遊玩；新增 4 個實作考試與 12 個資格任務，共 35 關。自由飛行、原有戰術模式與試飛不加資格限制。
- 新增「飛行駕照」入口。私人駕照無先修；商用與戰術需私人駕照；儀表資格需商用駕照。此為遊戲資格，不代表真實航空執照。
- 考試要求依序三航點、符合 IAS／離地高度／姿態與過載條件的累計飛行時間、返場對正跑道停住及落地下沉率。錯誤過載或重落地會顯示失敗原因。不是碰到單一航點即可取得資格。
- 資格任務列表明示所需駕照、是否具備資格、報酬與首通飛機獎品。未取得資格時，按鈕停用，啟動函式亦阻擋直接啟動。
- 新任務包含島嶼導航、側風返場、晨間飛行、廣體機甄選、夜航、低能見度、雨後進場與戰術轉彎。皆為當地三航點訓練，沒有宣稱新增武器交戰或真實貨物交付。
- 新資格任務基本金幣 18,000–72,000，另沿用首通／表現與航點加成。四項飛機獎品為 747-400、777F、An-124、F-14B。永久所有權沿用機庫與商店資料。

## 保存與結算
- 在既有 skybound.career.v1 加入 licenses、licenseReceipts，不移除舊存檔欄位。
- 新任務每次執行有唯一 runId；金幣、取得資格、飛機所有權與該次紀錄同步寫入同一 JSON。相同 runId 不重複入帳。新一次重試成功仍可正常賺取重玩報酬。
- 儲存失敗不頒發資格或飛機，畫面提示重試結算。存檔仍限目前瀏覽器，沒有伺服器帳號同步。

## 驗證
- 56 項 Node 測試通過。新增驗證先修關係、不足航點／穩定時間不得通過、落地條件、空速範圍、舊任務開放、資格保存、飛機獎勵、重複入帳與儲存失敗。
- verify-licensing-ui.py 在 Edge、WebKit 844×390 模擬手機中，從駕照入口測試鎖定任務、啟動私人考試、重現合格落地狀態、結算發照、重載及商用借機考試。兩者無頁面錯誤。
- 考試完成為可重現狀態測試，未宣稱人工飛完全部 35 關，也未宣稱實體 iPhone 已驗收。
- 約 5–10 分鐘為一般訓練速度的設計目標；飛行速度、快轉、操作與重飛會影響時間，尚未逐關量測實際完成時間。
