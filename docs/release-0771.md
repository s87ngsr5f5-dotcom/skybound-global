# 0.77.1 — 教練機速度、任務容錯與畫面穩定

- C172 高速遊戲模式以實際 IAS 約 800 km/h 為上限；限制作用於相對氣流的三軸速度，再加回風，位置依該速度推進。不是修改儀表數字，也不代表真實 C172 性能。寫實模式與其他機型不套用此上限。
- C172 的高動壓遊戲模式加入溫和姿態穩定，手動俯仰及滾轉反應減緩；低速自動降落仍使用原調校，避免破壞離島進場。
- 移除人工失速／G-buffet 對俯仰施加的抖動。保留升阻、失速警告與 G 數值計算。外部跟拍高度增加平滑，座艙不再附加 G 頭部晃動或轉彎預看偏移。
- 關閉跨音速凝結錐、擴張圓環與空中翼尖球狀煙團；保留戰機尾焰、加力與地面接地煙霧。
- G 力不再限制駕照通過、穩定時間累計、一般任務獎金或星等。星等仍參考程序警示及完成時間。
- 私人／商用／儀表／戰術考試穩定時間改為 20／35／45／20 秒，其他資格任務也縮短。私人教練機穩定速度範圍為 IAS 80–800 km/h，並加入少量讀值容差。
- 教練機航點半徑由 450 增至 900m，其他局部航線由 850 增至 1400m；垂直容差增至 300m。仍須按次序通過三個航點。
- 駕照落地評分放寬至約 6 m/s。局部訓練任務的接地物理容錯放寬（仍須在跑道內、放下起落架並大致對正），其他一般飛行不變。仍須落地停住，不會只碰地就發獎。

## 驗證
- 58 項 Node 回歸測試通過，包含實際速度／地圖位移、風向速度、120 秒教練機巡航、訓練限定落地容錯與高攻角下不注入抖動。
- 島嶼自動降落（綠島、蘭嶼）與現有客機自動進場回歸保留通過。
- Edge、WebKit 模擬手機中，以 20 秒穩定紀錄、12G 遙測及 -5.5m/s 合格落地狀態重現考試結算，確認會發照、存檔與開放商用借機考試，無頁面 JS 錯誤。此為狀態重現，不宣稱人工飛完所有任務或實體 iPhone 驗證。
