# 0.76.2 — 飛機圖示與分享封面
- 以本專案既有 G700 模型進行程式 3D 渲染，新增飛機圖示，取代空 favicon 所造成的預設字母。
- 提供 favicon.ico、64px 瀏覽器 PNG、180px Apple Touch Icon、192／512px 安裝圖示，以及 manifest。
- index、iphone、latest 三個入口都提供圖示與 Open Graph／Twitter 分享圖片資訊。分享圖為程式生成城市與既有機型，不是真實地圖攝影。
- 原首頁選單、控制、存檔、駕照與任務邏輯不變。既有瀏覽器捷徑與社群平台可能快取舊圖示，網站無法強制清除平台快取。
- 新圖示與封面皆為本輪程式渲染，沒有下載外部圖片或使用 AI 生成圖。
