# 0.74.2 飛行中環視

- 手機在飛行畫面的空白區拖曳，可水平 360 度環視、上下查看。座艙維持原座位，機外維持追蹤模式並環繞飛機；不切換第一／第三人稱。
- 放手後保留方向。空白區點兩下回正，電腦使用右鍵拖曳、Home 回正。
- 搖桿、油門、方向舵、按鈕與地圖有獨立觸控；支援一指控制搖桿、另一指環視。
- 拖曳後暫時抑制座艙射線點選，避免環視放手時誤切開關。取消手勢、離開視窗及旋轉螢幕會釋放拖曳。
- 不修改飛行物理、任務、空速／高度刻度帶或存檔格式。既有座艙 yaw 存檔接受完整環視角度。

驗證：Edge / WebKit 的環視累積超過 360 度、模式保持、飛機航向與坡度不受環視改動、雙指搖桿／環視互不覆寫、雙點回正、座艙後方可查看、地圖可點擊。實際渲染檢查機外攝影機位置會隨拖曳改變，而非僅修改數值。測試使用自動化事件與桌面瀏覽器；未使用實體 iPhone。貨艙、客艙專用鏡頭與拖車展示鏡頭未新增環視。
